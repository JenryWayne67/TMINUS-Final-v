# Phase 3 acceptance / playtest checklist

- Launch local URL. Check menu title and release.json read `5.3.0`; no missing ES module requests or console exceptions.
- Enter Competitive Offline Practice; select HANDS-ON + CREW, and assign at least one core component per specialist.
- Verify the selected specialist can purchase a part with E, carry it without clipping, turn with R / wheel, position at 3m outline and weld 3 distinct fasteners with LMB. The personally secured component awards Hands on Deck.
- Verify bot crew stages progress physically; obstruct a teammate long enough to test the 10s remote service-arm fallback; confirm it never secures the currently selected human role's components. Switch roles mid-carry and verify state transfer.
- Test machine assistance mid-assembly. Existing mounted parts must not be charged twice; the final credit balance should account for all 12 components exactly once.
- Open J mission journal, scroll panel, close journal, and confirm scroll/state does not reset at every HUD refresh.
- Stow 4 cases, complete 3 tests, choose a viable orbital route, land Planet B, extract and load real flags. Contract First Discovery must remain earned if a flag is dropped or intercepted.
- Shoot a rock/cover (no combat contract credit), shoot a rival target (contract progress and hit notification), test weapon reload and shield effects. Check mouse look/pointer lock handling on Safari.
- Dock and physically deliver a flag on Planet A. Verify board and debrief award Science Home only for delivered cargo, not for onboard cargo.
- Finish one match, note XP, credits, match count; reopen debrief if possible and ensure no double payout. Start a second match and verify browser-local rank persists.
- Test FAST ASSEMBLY from the lobby. Compare charges with manual mode. Verify 12 parts install in ~15s; no Hands on Deck contract is earned.
- On Mac Safari and desktop Chromium: test aspect ratios 16:9, 4:3, 21:9, 1280x720; low/medium/high graphics; tab focus, pause during a weld, skipped intros, and page reload.
- Test both original solo campaign missions; Phase 3 must not regress their start, tasks or end screens.
